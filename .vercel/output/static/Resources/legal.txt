Warlock Chainsaw Distortion VST3 1.1.0
Nihil Audio
com.nihilaudio.warlock
Installer: Warlock_Distortion_Setup_x64

x64 host required.

This browser instrument models the Warlock VST3 signal path:
input noise gate (1 ms attack, 5–200 ms release), 4× oversampled
diode clip (SYM ±0.65 / ASYM +0.35/−0.75), Swedish EQ stack
(320 Hz HPF, 1.2 kHz Q3 +14 dB, Grim 950 Hz, Cold 4.1 kHz),
then optional 4×12 cabinet convolution and output level.

CabinetIR.wav is a synthetic 48 kHz mono impulse (Vintage 30 /
SM57-style), installed to Contents/Resources. It is not a sampled
commercial cabinet.

Processing stays in the browser. No audio is uploaded.
